SmartEnergy Hub Supervision énergétique — Spring Boot · Redis · Cassandra · MongoDB

Comment lire ce tableau de bord ?
  1. Des capteurs (ici simulés) mesurent la puissance électrique (en kW) d'un équipement toutes les secondes.
  2. Chaque mesure traverse la chaîne ci-dessous : le Collector la vérifie, Redis la met en file d'attente, le Storage l'enregistre dans Cassandra (historique) et MongoDB (capteurs et totaux du jour), puis Analytics calcule moyennes, anomalies et prévision.
  3. Cette page lit simplement ces résultats : elle ne calcule rien elle-même.
  4. Pour voir quelque chose : cliquez sur « Lancer la simulation » en haut à droite.

Collector

reçues – · rejetées –

1. Porte d'entrée : vérifie chaque mesure. Rejetées = mesures invalides refusées.

Redis Streams

backlog – · en attente –

2. File d'attente rapide. Backlog = messages pas encore lus ; en attente = lus mais pas encore enregistrés (0 = tout est à jour).

Storage

stockées – · doublons –

3. Enregistre dans les bases. Doublons = même mesure envoyée deux fois, ignorée.

Analytics

prévision –

4. Calcule les indicateurs, détecte les anomalies et prévoit la suite.

Puissance (kW)

mesures seuil du capteur anomalie prévision

Chaque point de la ligne bleue est une mesure. La ligne orange est la limite autorisée du capteur : au-dessus, c'est un dépassement (points rouges). Les pointillés violets sont la prévision des prochaines secondes. Passez la souris sur la courbe pour lire une mesure.

Anomalies détectées

seuil : la puissance dépasse la limite du capteur. z = … : la valeur s'écarte beaucoup de la moyenne (z > 3 = très inhabituel).

HeurePuissanceDétection

Démo : envoyer une mesure

Mesure normale : valeur habituelle, acceptée. Pic : valeur trop haute, acceptée puis signalée comme anomalie. Mesure invalide : refusée par le Collector (erreur 400), rien n'est enregistré.

Les mesures partent vers le Collector (POST /api/measurements) puis traversent Redis → Storage → Cassandra/MongoDB.

Prévision

Estimation de la puissance dans les prochaines secondes. MAE / RMSE = erreur moyenne de la prévision en kW (plus petit = meilleur). Persistance = on suppose que la valeur reste la même ; droite = on prolonge la tendance.
